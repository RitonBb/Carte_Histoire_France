## 🛠️ Outils Développés

### 1. Script d'Enrichissement Curé (`enrich-data.js`)
- Base de données de 29 événements historiques français vérifiés
- Validation stricte de la qualité
- Détection automatique des doublons
- Aucune dépendance réseau
- Exécution instantanée

### 2. Script d'Interrogation d'API (`fetch-events.js`)
- Interroge Wikidata et Wikipedia
- Requêtes SPARQL pour événements historiques français
- Enrichissement automatique avec descriptions Wikipedia
- Validation stricte des données
- Respect des limites des APIs

### 3. Package.json
Scripts npm pour faciliter l'utilisation :
- `npm run enrich` : Ajoute 10 événements
- `npm run enrich-more` : Ajoute 20 événements
- `npm run enrich-all` : Ajoute tous les événements disponibles
- `npm run validate` : Valide la syntaxe de tous les fichiers

## ✅ Critères de Qualité Respectés

Chaque événement ajouté respecte TOUS ces critères :

1. ✅ **Titre clair** (minimum 5 caractères)
2. ✅ **Description détaillée** (minimum 50 caractères)
3. ✅ **Coordonnées GPS précises** (latitude, longitude)
4. ✅ **Date historique vérifiable**
5. ✅ **Localisation précise** (ville, région)
6. ✅ **Catégorie appropriée**
7. ✅ **Sources vérifiables** (Wikipedia, Wikidata)
8. ✅ **Aucun doublon**
